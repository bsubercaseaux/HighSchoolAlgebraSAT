# HighSchoolAlgebraSAT
A SAT attack on Tarski's high school algebra problem

## Formula generation

Our encoder is implemented in `simp_enc.py`. It requires the PySAT library, which can be installed via `pip install python-sat`.

To generate the CNF formula $\Omega_n$ as described in the paper, run:
```
python3 simp_enc.py -n <n> 
```
so for instance, to generate $\Omega_{11}$, oen should run `python3 simp_enc.py -n 11`.
This will output the formula to a file named `w_<n>.cnf` in the same directory.

To obtain the formula corresponding to the Gurevič's identity countermodel, run
```
python3 simp_enc.py -n 13 --exp-2-4-5
```


## Lean verification encoding

The Lean formalization and verified CNF encoder live in `LeanVerification/`.
The encoder is a Lake executable named `wilkies_cnf`, and the main theorems are placed in the `Wilkies/Correctness.lean` file.


Prerequisite: install Lean 4 with `elan`. The checked-in `lean-toolchain`
file pins the Lean version used by this project.

To generate the DIMACS CNF formula for a size parameter `n >= 5`, run e.g.,:

```sh
cd LeanVerification
lake build
lake exe wilkies_cnf 8 > ../lean_encoding_8.cnf
```

Replace `8` with the desired value of `n`. The output file will be written at
the repository root as `lean_encoding_{n}.cnf`; for example, the command above
creates `lean_encoding_8.cnf`.

One can then check the byte-for-byte equivalence of the CNF that Lean considers with the one generated by our python3 code by running
```sh
diff lean_encoding_8.cnf w_8.cnf
```
The output should be empty.
